# DBMS MINI PROJECT — PantryChef
Smart recipe finder built with Next.js, PostgreSQL, and pgvector.
## Team
- Member 1: Tarun Jagan
- Member 2: Tanishk Gowda
## Run the application
1. Extract the supplied `PantryChef-Complete.zip` (archive upload to this repository is pending).
2. Read `START-HERE.txt` inside the extracted `PantryChef-App` folder.
3. On the configured Windows computer, double-click `RUN-PANTRYCHEF.cmd`.
4. Open http://127.0.0.1:3000/.
On a new computer, install the prerequisites described in the included README before running setup.
The archive includes the frontend, backend, database seed and migrations, launcher, tests, screenshots, and project documentation. Private credentials and installed dependencies are excluded.
## Database features
Ingredient coverage matching, full-text search, vector similarity, transactions, views, stored functions, triggers, indexing, and user/admin authorization.
